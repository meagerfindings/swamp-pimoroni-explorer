# swamp-pimoroni-explorer

[Swamp](https://swamp.club) extension `@mgreten/pimoroni-explorer` for inspecting and controlling a USB-connected Pimoroni Explorer running MicroPython.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install beta:** `swamp extension pull @mgreten/pimoroni-explorer --channel beta`

## Repository layout

This repository is a Swamp workspace. The publishable extension lives under [extensions/models/](extensions/models/).
